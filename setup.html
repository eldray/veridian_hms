Database setup

Veridian HMS stores its data in PostgreSQL. Enter the connection details of the PostgreSQL server for this hospital (on this PC, or the hospital server).

PostgreSQL server
Administrator account (new database only)

PostgreSQL is not installed by Veridian HMS. If it is not installed yet, install PostgreSQL 14 or newer first, then come back here. Your settings are stored on this PC only, and the password is encrypted with your Windows account.
